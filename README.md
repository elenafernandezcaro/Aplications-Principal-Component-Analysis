# Aplications-Principal-Component-Analysis
Interactive Google Colab environment and experimental framework for my Undergraduate Dissertation (TFG) on Principal Component Analysis (PCA) and its applications in Data Science, featuring standard PCA and Probabilistic PCA (PPCA).
# Análisis de Componentes Principales y su Aplicación en Ciencia de Datos

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/TU_USUARIO_DE_GITHUB/TU_REPOSITORIO/blob/main/GRAFICAS_TFG_(2).ipynb)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Este repositorio contiene el entorno experimental, los scripts de desarrollo y los recursos multimedia orientados a la elaboración de las figuras e ilustraciones técnicas incluidas en la memoria del **Trabajo de Fin de Grado (TFG)** titulado *"Análisis de Componentes Principales y su Aplicación en Ciencia de Datos"*.

El objetivo principal de este cuaderno interactivo es proporcionar un marco de trabajo 100% reproducible para el estudio geométrico, estadístico y computacional del análisis de componentes principales (PCA), evaluando su rendimiento tanto en tareas de compresión y visualización como en entornos de reconstrucción de datos con estructuras latentes.
